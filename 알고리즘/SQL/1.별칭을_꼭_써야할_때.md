### 별칭 (Alias) 를 꼭 써야할 때 

#### 1. CTE에서 별칭 지정
외부에서 참조할 때 이름을 지정해주어야 함.
```sql
with `별칭` AS (

)
SELECT * 
FROM `별칭`
```

#### 2. 집계 함수 사용시 별칭 지정
`sum`, `max`, `avg`, `count` 를 사용한 결과값을 외부 쿼리에서 참조할 때 별칭을 지정 해야 함.

```sql
SELECT id, MAX(salary) `as max_salary`
FROM employees
GROUP BY id;
```


#### 3. 서브쿼리에 별칭 지정
서브쿼리를 사용할 때 서브쿼리 자체에 별칭을 지정해줘야 함.
별칭이 없으면 해당 서브쿼리의 결과를 외부 쿼리에서 참조할 수 없어 오류 발생

```sql
SELECT e.id, e.name, dept.max_salary
FROM employees e
JOIN (
    SELECT id, MAX(salary) as max_salary
    FROM employees
    GROUP BY id) `as dept`
ON e.id = dept.id;
```
